# Numeral

An oversized count for listicles ("7 Costly Mistakes") and carousel step numbers; the number is type, never a 3D image.

**Markup:** `p.ci-numeral` (+ `.ci-numeral--gold` on Navy or once per carousel).

- Do: pair with a `.ci-title` beneath and a `.ci-rule` between.
- Don't: more than one numeral per slide.
