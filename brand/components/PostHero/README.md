# PostHero

The Daylight cover post for advisory carousels (left: as published; right: with the 6-column grid).

**Structure:** `.ci-post.ci-post--mist` > `.ci-post__head` (logo) · `.ci-post__main` (HeadlineStack, Pointer) · `.ci-post__image` (the cut-out subject; this preview shows the empty slot) · `.ci-post__foot` (website + SwipeCue).

**Consumer provides:** headline words, one pointer, one cut-out image (PNG, subject only, cool high-key light), the carousel length.

- Do: top-right corner empty — Instagram's carousel icon covers it.
- Don't: centre the headline, add a second pointer, or put text inside the image slot.
