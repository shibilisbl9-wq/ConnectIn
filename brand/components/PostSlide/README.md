# PostSlide

The inside slide of a carousel: one point, one numeral, ≤40 words, no photo.

**Structure:** `.ci-post` > `.ci-post__head` (`.ci-label` counter) · `.ci-post__main` (Numeral, rule, `.ci-title` with one `<em>` gold word, `.ci-body`, optional WarnMark or FactChip) · `.ci-post__foot`.

- Do: logo only on the first and last slide.
- Don't: more than 40 words. If it needs more, split the slide.
