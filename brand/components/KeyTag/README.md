# KeyTag

The navy tag that names the topic or place under the keyword; the most recognisable ConnectIn element, so it stays exactly as it is.

**Markup:** `span.ci-tag` (caps) or `span.ci-tag.ci-tag--soft` (sentence case, italic). Colours come from `tag` / `on-tag`, which flip to gold-on-navy in the Navy theme.

- Do: 1–3 words. One tag per post.
- Don't: stretch it full width, outline it, or put an icon inside.
