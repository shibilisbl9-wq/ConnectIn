# FactChip

One number and one promise on a navy panel; the most persuasive line format the feed has.

**Markup:** `div.ci-fact` > `b` (the number, max ~8 characters) + `span` (max 8 words).

- Do: real, checkable figures (timelines, fees, thresholds).
- Don't: vague numbers ("100% hassle-free"). If you can't source it, don't chip it.
