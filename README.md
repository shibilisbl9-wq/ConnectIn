# ConnectIn

Brand design system for ConnectIn Business Services' Instagram feed.

- `brand/README.md`: brand book (colour, type, layout, imagery, marks)
- `brand/guidelines/`: feed audit, post templates, voice and copy
- `brand/tokens.json`: design tokens (Daylight and Navy themes)
- `brand/components/`: post components (`bundle.css`) with previews and usage notes
- `brand/assets/Logos/`: official logo (as supplied) and a derived reversed version for navy
- `brand/fonts/`: Urbanist variable fonts (SIL OFL 1.1)
- `brand/samples/`: three template posts at 1080 x 1350 (HTML and PNG)
